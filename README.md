### Sobre mí

Desarrolladora Full Stack con foco en backend — construyo APIs y sistemas que funcionan en producción, no solo en el laboratorio. Mi stack principal es **C# con ASP.NET Core**, pero me muevo con comodidad por todo el ciclo: desde modelar una base de datos hasta maquetar una interfaz.

Trabajo con **Docker**, **Nginx** y pipelines **CI/CD con GitHub Actions** para entregar software que se despliega limpio y escala sin drama. Me gusta la metodología **Scrum** para trabajo en equipo real — sprints, retrospectivas y entregas iterativas.
